# Four-Minute Demo

**0:00–0:25** — “Code assistants edit files. Whitebox models states, side effects, integrations, dependencies, and failure boundaries—then fixes only what it can prove safe.”

**0:25–0:45** — Send `/whitebox <DEMO_REPOSITORY> --goal "stabilize checkout"`; open the immediate Cloudflare run URL.

**0:45–1:20** — Show the real Hermes run/session ID, manager plan, specialist task hierarchy, and live stage changes.

**1:20–2:00** — Open Logistics Map. Trace entry → payment → state write → inventory. Show invariant and dependency blast radius.

**2:00–2:40** — Open exact code evidence, one verified repair/schema delta, one rejected timeout false positive, and one escalated unsafe repair.

**2:40–3:15** — Open the real PR, separate commits, compact artifacts, and validation proof.

**3:15–3:35** — Open an incremental run: changed files, impact cone, schema versions, resolved/unchanged/new/regressed counts, and eval score.

**3:35–3:48** — Open a Whitebox Block on the same exact range and follow its dashboard link.

**3:48–4:00** — “Vibe coding generates code. Whitebox maintains the living logic that keeps the entire codebase coherent.”

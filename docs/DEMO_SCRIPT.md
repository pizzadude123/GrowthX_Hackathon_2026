# Four-Minute Audit-Only Demo

**0:00–0:30** — Explain the boundary: Whitebox accepts a public GitHub repository, freezes an immutable commit/tree/blob snapshot, and never executes or modifies submitted code.

**0:30–0:55** — Send `/whitebox <PUBLIC_REPOSITORY> --goal "review critical flows"`; open the returned dashboard URL. The goal is private command context and is not published or sent to producers.

**0:55–1:35** — Show source binding, explicit coverage dispositions, and the two isolated Hermes roles: Repository Auditor proposes candidates and Verification Lead dispositions those exact IDs.

**1:35–2:20** — Open one accepted finding. Verify its repository path, exact line range, verbatim excerpt, trusted semantic detector, source node, scoped flow, and invariant. Show an unrecognized or disproved candidate remaining rejected.

**2:20–3:00** — Show the versioned Living Code Logistics Schema and canonical audit-only Markdown/PDF/Telegram artifacts. Confirm dependency health remains `unverified` when no registry or advisory lookup occurred.

**3:00–3:35** — Show attempt-, source-, producer-, runtime-, and destination-bound signed receipts plus monotonic completion and delivery state. Keep internal IDs and receipts off public surfaces.

**3:35–4:00** — State the authority honestly: findings are advisory; repair, repository writes, commits, branches, pull requests, and merges are disabled.
